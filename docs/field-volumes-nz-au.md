## Key verified numbers (highest confidence)

- Parihaka 3D: 4 SEG-Y volumes ≈ **20.4 GB total** (5.1 GB each, byte-exact via HTTP HEAD)
- Opunake 3D full stack: **10.4 GB**; Kerry 3D: **1.1 GB**
- Poseidon: `s3://tgs-opendata-poseidon` (CC BY 4.0, MDIO) + TerraNubis SEG-Y/OpendTect ≈ **50 GB**
- GSQ: **1,402** open seismic datasets with SEG-Y
- SARIG: **>8,000 lines / >150,000 line-km** 2D SEG-Y

1. **No Geoscience Australia-owned bucket on registry.opendata.aws** — the only Australian seismic entry is TGS's `tgs-opendata-poseidon`. GA's seismic sits behind NOPIMS, not a public S3 registry entry.

3. **NOPIMS total archive size / biggest released 3D surveys** — NOPIMS is an Angular SPA, not scrapeable; GA publishes no aggregate TB figure.
4. **Waihapa 3D S3 key and exact size** — SEG wiki behind Cloudflare; bucket denies listing; five candidate paths returned 403.
5. Exact sizes of Ceduna/Bight, Gippsland, Otway offshore 3Ds; SARIG package byte sizes (CKAN `size` null); NZASSDR volume; Victoria GSV pages (403).
